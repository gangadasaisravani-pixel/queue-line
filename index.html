💾 In-Memory State

Queue positions and issued tokens are held in active server memory. State gracefully resets when the backend restarts. Ideal for testing and demonstrations.

⏱️ Heuristic Waiting Formula

Estimated waiting times are calculated with a consistent 3-minute-per-student rule of thumb: (position - 1) × 3 mins. No opaque AI predictions.

Fully integrated with native FastAPI endpoints (/services, /join-queue, /queue/{id}) via relative URLs on the same origin.
